Implement `ApprovalWorkflow` in `src/document_approval_workflow/__init__.py`.

`submit(submitter, department, amount_cents)` validates a non-negative integer amount and returns a stable unique request mapping in `pending_manager` status. `approve(request_id, actor, role)` allows a manager approval followed sequentially by finance approval; then status is `approved`. `reject(request_id, actor, role)` is allowed only for the currently required role and makes status `rejected` permanently. The submitter may never approve their own request. Invalid roles, order, actors, IDs, or transitions raise `ValueError`/`KeyError` without changing state. `get(id)` returns the current mapping.
