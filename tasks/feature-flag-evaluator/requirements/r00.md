Implement `FlagEvaluator(flags)` in `src/feature_flag_evaluator/__init__.py`.

Each flag maps a key to `{"enabled": bool, "rollout": integer_percent}`; rollout defaults to 100 and must be from 0 through 100. `evaluate(flag_key, user)` returns false for a known disabled flag. An enabled flag deterministically assigns the same user ID to its percentage rollout on repeated calls. `user` contains a string `id`. Initially hash only the user ID with SHA-256, use the first eight digest bytes as an unsigned integer, and enable when `value % 10000 < rollout * 100`. Unknown flags return false. Invalid configuration or missing user IDs raise `ValueError`.
