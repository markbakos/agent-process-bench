Implement `Scheduler` in `src/appointment_scheduler/__init__.py` using naive `datetime` values.

`book(provider, start)` creates a 30-minute appointment and returns a mapping containing a stable unique string `id`, `provider`, `start`, `duration_minutes`, and `status`. The clinic is open Monday through Friday from 09:00 inclusive to 17:00 inclusive as an ending boundary; an appointment must fit fully inside those hours. Appointments for the same provider may touch but may not overlap. Different providers may overlap. Invalid bookings raise `ValueError` without changing the schedule.

`cancel(appointment_id)` removes an appointment and frees its slot. `reschedule(appointment_id, new_start)` keeps its ID and applies the same validation atomically. `list_appointments(provider=None)` returns active appointments ordered by start then ID. Unknown IDs raise `KeyError`.
