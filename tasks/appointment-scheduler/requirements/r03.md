Revise working hours to support provider-specific configuration.

`Scheduler(provider_hours=None)` accepts a mapping from provider to a weekday-hours mapping. Weekdays use integers 0 through 6 and each value is a `(datetime.time opening, datetime.time closing)` pair. A provider present in this configuration is bookable only during its configured days and hours. A provider with no specific configuration uses the current clinic defaults. Validate the entire appointment against the selected provider's hours.
