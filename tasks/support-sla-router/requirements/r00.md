Implement `SLARouter(category_queues, priority_sla_minutes)` in `src/support_sla_router/__init__.py` using naive datetimes.

`create_ticket(category, priority, created_at)` returns a ticket mapping with stable unique `id`, the inputs, an assigned `queue`, and `deadline`. Categories map to queues, while an unknown category uses `"general"`. Priority selects a positive SLA duration in minutes; unknown priorities raise `ValueError`. The initial deadline is elapsed wall-clock time: `created_at + SLA minutes`.
